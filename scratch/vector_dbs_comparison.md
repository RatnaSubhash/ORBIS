# Local-First Vector Databases Comparison

## Overview
Comparative evaluation of local-first vector search libraries including FAISS, ChromaDB, and SQLite-VSS.

## Key Findings
- **FAISS**: Ultra-low latency (<2ms) CPU/GPU indexing; ideal for embedded local search.
- **ChromaDB**: Higher-level abstraction with metadata filtering; Python server overhead.
- **SQLite-VSS**: In-process relational integration; convenient for single-file data persistence.
