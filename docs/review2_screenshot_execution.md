## 1. Capture Environment Setup

Prior to executing capture sequences:
1. **Launch FastAPI Gateway:**
   ```powershell
   cd c:\Projects\ORBIS
   .\.venv\Scripts\python.exe -m uvicorn core.gateway.app:create_app --host 127.0.0.1 --port 8000
   ```
2. **Launch Frontend Client (Electron or Browser):**
   ```powershell
   cd c:\Projects\ORBIS\frontend
   npm run dev:electron
   ```
   *(Alternatively, for headless/browser capture: `npm run dev` at `http://localhost:5173`).*
3. **Display Configuration:** Resolution set to 1920x1080, Windows dark mode enabled, DPI scaling 100%.
