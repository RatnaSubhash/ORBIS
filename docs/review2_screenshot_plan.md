# ORBIS REVIEW-2: SCREENSHOT INVENTORY & EVIDENCE PLAN

**Document Reference:** `docs/review2_screenshot_plan.md`  
**Purpose:** Actionable, high-fidelity visual evidence catalog for the Review-2 technical report and presentation.  
**System Verification:** Every listed screenshot corresponds to a functional, verified UI state in the current ORBIS desktop client (`frontend/src/`) and FastAPI backend.

---

## 1. Screenshot Standards & Protocol

1. **Resolution & Environment:** 1920x1080 (Full HD) or 2560x1440 (QHD) on Windows 11 with dark mode enabled.
2. **Visual Style:** Authentic matte obsidian UI (`#0a0b0e`, `#12151c`), clean glassmorphism surfaces (`FluidGlass`), and Lucide icons without browser address bars (captured directly within Electron or Vite renderer).
3. **Data Integrity:** Real session data populated from `orbis.db` (events, Context DNA, session timelines) or deterministic test task execution.
